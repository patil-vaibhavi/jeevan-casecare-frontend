# Jeevan CaseCare Frontend

React + Vite + Bootstrap 5 starter for the Jeevan CaseCare healthcare platform.

## Run locally

```bash
npm install
cp .env.example .env
npm run dev
```

The current starter includes:
- Premium dark clinical design system
- Landing page
- Login page
- Role selection
- Patient dashboard
- Doctor dashboard
- Responsive sidebar and topbar
- Bootstrap 5 and Bootstrap Icons

Backend API base URL is configured through `VITE_API_BASE_URL`.
